# Admin Panel

## Dashboard KPIs
- Revenue
- Confirmed bookings
- Pending bookings
- Upcoming events
- Outstanding payments
- New customers
- Conversion rate

## Modules
### Bookings
Search, filter, create, edit, quote, confirm, cancel, assign staff, update status, add internal notes.

### Calendar
Day/week/month views, availability blocks, event details, staff assignments.

### Customers
Profiles, booking history, notes, invoices, payments, contact details.

### Catalog
Packages, themes, services, add-ons, venues, pricing, availability, images.

### Operations
Staff, vendors, tasks, event checklists.

### Finance
Payments, invoices, refunds, outstanding balances, discounts.

### Content
Pages, homepage sections, gallery, reviews, FAQs, banners, navigation, SEO metadata.

### Reports
Revenue, bookings by package/theme, cancellation rate, outstanding balances.

### Settings
Business information, service areas, working hours, currencies, taxes, notification settings, integrations, roles.

## Admin UX Rule
Destructive operations require confirmation and should display impact clearly. High-risk actions should be logged.
