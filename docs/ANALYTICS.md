- Booking submissions
- Confirmed bookings
- Conversion rate
- Average order value
- Revenue by month

## Admin Dashboard Filters
- Date range
- Event type
- Package
- Theme
- Location
- Status

## Event Tracking
Use stable event names such as:
```text
view_package
view_theme
start_booking
submit_booking
payment_started
payment_completed
booking_confirmed
contact_clicked
whatsapp_clicked
```

Do not collect unnecessary personal data in analytics payloads.
