# CMS

## Goal
All business-facing website content should be manageable from the admin panel without a code deployment.

## Editable Areas
- Logo and brand assets
- Homepage hero
- Headlines and copy
- Packages
- Themes
- Services
- Add-ons
- Gallery
- Testimonials/reviews
- FAQs
- About page
- Contact details
- Social links
- Footer
- Navigation labels/ordering
- Promotional banners
- SEO title/description/canonical
- Open Graph image

## Content Model
Prefer structured content for important business entities and section-based content for marketing pages.

## Publishing States
```text
DRAFT -> PUBLISHED -> ARCHIVED
```

## Safety
- Validate uploaded HTML/rich text.
- Restrict allowed embeds.
- Maintain revision history for important pages.
- Preview before publishing.
