# Media Management

## Media Categories
- Logo/brand
- Package images
- Theme images
- Service images
- Gallery photos
- Customer/event uploads
- CMS assets

## Requirements
- Object storage, not DB blobs for normal images/videos.
- Store metadata in database.
- Generate optimized variants/thumbnails.
- Preserve original where business needs it.
- Support focal point/crop metadata when useful.

## Admin Controls
- Upload
- Replace
- Reorder
- Alt text
- Caption
- Folder/category
- Visibility
- Delete/archive
