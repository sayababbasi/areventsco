# Notifications

## Customer Notifications
- Booking received
- Booking quoted
- Booking confirmed
- Deposit/payment received
- Payment reminder
- Event reminder
- Event completed
- Invoice available
- Review request

## Admin Notifications
- New inquiry
- New booking
- Payment received
- Cancellation
- Failed payment
- New review

## Channels
Primary:
- Email

Optional:
- WhatsApp
- SMS

## Rule
Notifications should be event-driven and sent asynchronously where possible. Store delivery status and provider message/reference IDs.
