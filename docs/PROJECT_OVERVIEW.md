# Project Overview

## 1. Vision
Build a premium, easy-to-use digital platform for AR Events Co. that lets customers discover birthday/event services, configure an event, request/book a date, pay online, receive confirmations, and manage their booking.

The internal team must be able to operate the business from one admin panel without editing code.

## 2. Primary Market
- Islamabad
- Rawalpindi
- Nearby serviceable areas as configured by admin

## 3. Initial Focus
Birthday planning and decoration, including:
- Birthday themes
- Decorations
- Backdrops
- Balloons
- Cakes
- Photography
- Entertainment
- Party add-ons
- Venue-related services where offered

## 4. Future Expansion
The domain model must allow:
- Weddings
- Engagements
- Mehndi/events
- Corporate events
- Private parties
- Graduations

## 5. User Types
### Visitor
Browse services, themes, packages, gallery, FAQs, and contact information.

### Customer
Create an account, create/request a booking, pay, view invoices, track booking status, receive notifications, and manage profile.

### Staff / Event Manager
View assigned events/tasks and operational details only within granted permissions.

### Admin
Manage bookings, customers, packages, services, themes, prices, content, payments, media, staff, vendors, reports, and settings.

### Super Admin
Full access including user roles, permissions, system configuration, integrations, audit logs, and destructive operations.

## 6. MVP Goals
1. Fast, mobile-first public website.
2. Booking flow from event selection to confirmation.
3. Admin-controlled content and pricing.
4. Calendar/availability management.
5. Customer and booking management.
6. Payment/invoice tracking.
7. Notifications.
8. Local SEO foundations.

## 7. Non-Goals for First Release
- Marketplace for third-party public vendors.
- Multi-company SaaS tenancy.
- Complex real-time collaboration.
- Native mobile apps.

## 8. Success Metrics
- Booking conversion rate
- Qualified inquiries
- Confirmed events
- Average booking value
- Deposit collection rate
- Repeat customer rate
- Lead-to-booking time
- Admin processing time
