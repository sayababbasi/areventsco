# SEO & Local Search

## Primary Goal
Rank AR Events Co. for birthday and event-planning searches in Islamabad and Rawalpindi.

## Core Pages
- Birthday Event Planner Islamabad
- Birthday Decoration Islamabad
- Birthday Decoration Rawalpindi
- Kids Birthday Planner Islamabad
- Surprise Birthday Decoration Islamabad
- Birthday Party Packages Islamabad
- Event Decoration Rawalpindi

Avoid creating thin doorway pages that differ only by city name.

## Technical SEO
- Semantic HTML
- Server-rendered/indexable content
- Unique title and meta description
- Canonical URLs
- XML sitemap
- Robots.txt
- Open Graph/Twitter metadata
- Image alt text
- Optimized image sizes
- Fast mobile performance

## Structured Data
Use appropriate schema such as:
- Organization
- LocalBusiness
- Service
- Event where genuinely applicable
- BreadcrumbList
- FAQPage only where eligible and content is visible on-page

## Local Business Data
Keep business name, location/service area, phone, hours, and social/contact information consistent across the website and external listings.

## Content Strategy
Create useful landing pages and blog/resource content around:
- Birthday themes
- Decoration ideas
- Party planning checklists
- Budget guides
- Venue selection
- Islamabad/Rawalpindi event planning tips

## Image SEO
Use descriptive filenames, useful alt text, modern formats, dimensions, lazy loading where appropriate, and no important text embedded only inside images.
