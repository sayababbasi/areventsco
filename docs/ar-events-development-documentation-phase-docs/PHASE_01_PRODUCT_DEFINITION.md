# Phase 01 — Product Definition

## Objective

Turn the business idea into an agreed product scope before implementation begins.

## Customer Scope

Primary launch market: Islamabad and Rawalpindi.

Launch focus:

- Birthday event planning
- Birthday decoration
- Party packages
- Add-on services
- Venue/event coordination where offered
- Booking inquiry and confirmation

Expansion categories are supported by the model but are not required for the first release.

## Core User Journeys

### Customer

1. Discover AR Events Co.
2. Browse services and packages.
3. Review themes, decoration options, and gallery work.
4. Select a package and date.
5. Add optional services.
6. Submit event details.
7. Receive confirmation and booking reference.
8. Track status, payment, and event details.

### Staff

1. Sign in.
2. Review assigned events.
3. Update preparation status.
4. Add internal notes.
5. Complete event checklist.

### Admin

1. Review new inquiries.
2. Confirm or decline bookings.
3. Manage packages, themes, services, availability, customers, staff, and content.
4. Track payments and outstanding balances.
5. Monitor revenue and upcoming events.

## Acceptance

The phase is complete when the main journeys, launch scope, and out-of-scope items are approved and reflected in the product documentation.
