# Phase 06 — Public Website

## Objective

Launch a polished, conversion-focused website that explains the service clearly and drives customers toward booking or enquiry.

## Pages

- Home
- About
- Services
- Packages
- Themes
- Gallery
- Venues
- Reviews
- FAQ
- Contact
- Book an Event
- Legal pages

## Homepage Priorities

1. Clear value proposition
2. Strong visual presentation
3. Package discovery
4. Proof through portfolio and reviews
5. Clear booking CTA
6. Islamabad/Rawalpindi service positioning
7. Contact options, including WhatsApp where appropriate

## CMS Requirement

Business content should not require a code deployment for normal changes. Text, images, packages, themes, reviews, FAQs, and promotional blocks should be manageable from the admin system.

## Exit Criteria

All agreed public routes are responsive, connected to real data where appropriate, and ready for content entry through the CMS.
