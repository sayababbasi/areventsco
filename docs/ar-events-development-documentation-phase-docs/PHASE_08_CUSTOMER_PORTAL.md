# Phase 08 — Customer Portal

## Objective

Give customers a clear place to manage their relationship with AR Events Co. after submitting an event request.

## Features

- Dashboard
- Upcoming events
- Booking details
- Status history
- Payment history
- Invoices
- Documents where required
- Messages/notifications
- Profile and contact details

## UX Requirement

A customer should be able to answer three questions quickly:

1. What is happening with my booking?
2. What do I need to pay or provide?
3. When and where is my event?

## Exit Criteria

Customers can view the current state of their bookings without needing to contact staff for routine status information.
