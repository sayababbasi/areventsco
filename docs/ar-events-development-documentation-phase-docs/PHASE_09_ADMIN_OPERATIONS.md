# Phase 09 — Admin Operations

## Objective

Deliver the business control center required to run the event-planning operation day to day.

## Modules

- Dashboard
- Bookings
- Calendar
- Customers
- Packages
- Themes
- Services
- Add-ons
- Venues
- Vendors
- Staff
- Payments
- Invoices
- Coupons
- Reviews
- Gallery / Media
- CMS
- Notifications
- Reports
- Users and permissions
- Settings
- Audit log

## Operational Priorities

The admin should be able to move from “new inquiry” to “event completed” without leaving the system for basic coordination tasks.

## Dashboard Metrics

- New inquiries
- Confirmed bookings
- Upcoming events
- Revenue
- Pending balances
- Cancellations
- Staff workload

## Exit Criteria

Business operators can manage the core catalog, bookings, customers, schedules, and content without developer intervention for normal changes.
