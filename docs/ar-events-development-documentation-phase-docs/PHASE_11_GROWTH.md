# Phase 11 — SEO, Analytics & Performance

## Objective

Prepare the platform for local discovery and measurable acquisition.

## SEO

Priority areas:

- Page titles and descriptions
- Clean URL structure
- Local service pages
- Structured data where appropriate
- XML sitemap
- Robots directives
- Canonical URLs
- Image metadata
- Internal linking
- Service-area content for Islamabad and Rawalpindi

The detailed SEO rules remain in `SEO.md`.

## Analytics

Track meaningful business actions, not just page views:

- Package views
- Theme views
- Booking starts
- Booking submissions
- Contact clicks
- WhatsApp clicks where applicable
- Completed payment steps
- Review submissions

## Performance

Targets should cover:

- Responsive rendering
- Image optimization
- Cache strategy
- API response time
- Core page load performance
- Admin table/calendar responsiveness

## Exit Criteria

The site can be indexed cleanly, key business conversions are measurable, and the critical customer journey meets the agreed performance target.
